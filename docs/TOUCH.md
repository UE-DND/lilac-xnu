# 触摸屏驱动移植

Sony Xperia XZ1 Compact 配备 Synaptics ClearPad S3330 触控芯片。触控芯片挂载于高通 BLSP1 QUP5 I²C 控制器总线上，物理寄存器基地址为 `0x0c179000`，从机设备地址为 `0x2c`。控制器最高支持 10 点多点触控输入，物理坐标解析上限为 719 × 1279，每个 F12 触点对象使用 8 字节结构描述。

## 硬件与时钟初始化

触摸屏正常工作需完成时钟源投票与上电复位时序：

1. **时钟控制器配置**：
   - 驱动配置高通 GCC 控制器的 BLSP1 AHB 时钟（时钟 ID `0x8caa5b4f`，寄存器偏移 `+0x17004`）与 QUP5 I²C 时钟（时钟 ID `0xacae5604`，寄存器偏移 `+0x21008`）。
   - QUP5 根时钟发生器（RCG2 位于 `+0x21020/24`）配置父时钟源为 19.2 MHz XO，确保 I²C 传输速率稳定在标准频率。
2. **引脚与供电时序**：
   - GPIO89 作为硬件复位引脚：驱动释放复位低电平并延时 100 ms 等待芯片微码就绪。
   - GPIO133 负责 VDDIO 供电使能：Sony In-cell 硬件规范要求保持低电平以开启 VDDIO 供电，避免意外拉高导致芯片断电。

## RMI4 协议栈解析与驱动架构

驱动代码分层清晰，全面覆盖协议解析与总线读写：

- **`kernel/lilac-qup-clock.h`**：负责 BLSP1 硬件时钟使能与 RCG2 状态校验。
- **`kernel/lilac-qup-i2c.h` / `kernel/lilac-qup-i2c-tags.h`**：实现基于 FIFO 模式的高通 QUP v2 协议帧构造，处理 I²C 起始、停止与分页读取序列。
- **`kernel/lilac-clearpad-bus.h` / `kernel/lilac-clearpad-rmi.h`**：实现 Synaptics RMI4 页面切换与功能描述符扫描。
- **`kernel/lilac-clearpad-f12.h`**：精确解析 F12 多点触控寄存器帧（触点有效位、X/Y 绝对坐标与指压数据）。
- **`sources/xnu/bsd/dev/lilac.touch.c`**：内核触摸主模块。系统引导传入 `lilac_touch=1` 时启用，依序执行 RMI 设备发现、F01 状态机唤醒配置与 F12 触点数据周期采集。

### 容错与状态机管理

在写入 F01 控制寄存器完成配置后，芯片状态由 `0x81` 自动转入就绪态 `0`。若在数据采集期间检测到 QUP 传输异常或数据校验不符，驱动安全跳过异常帧并继续监听，防止内核状态紊乱。

## 用户空间虚拟 HID 桥接

当用户空间桌面启用触摸支持（`--touchscreen`）时，内核向用户态发布 `/dev/hakios-touch` 字符设备。

系统在启动 `backboardd` 时注入虚拟输入桥接库，桥接库读取内核触点事件并将其打包封装为 iOS 原生 `IOHIDEvent` 数字化仪触控事件（Digitizer Events），平滑分发至窗口管理服务。

## 虚拟 Home 键手势

Sony Xperia XZ1 Compact 采用全面屏手势与虚拟按键设计，未配备物理 Home 按键。为了满足 iOS 16.5 锁屏唤醒与退回主屏幕的需求，驱动在用户态桥接层实现了“三指轻点”手势识别：

- **触发时序与判定**：
  - 3 个触点在 180 ms 的时间窗内依次落于屏幕。
  - 完整触碰过程持续在 40–600 ms 之间，并在超时前全部松开。
  - 判定期间若出现触点大幅位移、产生第 4 个触点或长按超时，手势识别自动取消并回退为常规多点触碰。
- **事件分发**：识别成功后，桥接服务向系统发送 Consumer Menu（Usage `0x40`）按键按下与释放事件，间隔 80 ms。

此外，系统保留“五指同时长按 1.5 秒”的底层调试手势，用于在非定时运行环境下安全触发系统停机并返回 BootShim 调试通道。
