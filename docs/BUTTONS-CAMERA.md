# 按键与后置相机适配

本文档阐述 Sony Xperia XZ1 Compact 上的物理按键驱动实现原理，以及 MSM8998 相机子系统的硬件调研与后续适配路径。

## PM8998 物理按键驱动

### 硬件映射与总线接口

设备树 `/soc/gpio_keys` 节点定义了物理按键与高通 PM8998 电源管理芯片（PMIC）的连接关系：
- **音量加键（Volume Up）**：连接至 PM8998 GPIO 7（外设基址 `0xc600`，逻辑偏移 6），低电平有效。
- **音量减键（Volume Down）**：连接至 PM8998 GPIO 6（外设基址 `0xc500`，逻辑偏移 5），低电平有效。
- **电源键（Power）**：连接至 PM8998 PON（Power-On）模块（外设基址 `0x0800`），实时状态寄存器偏移为 `0x10`，`KPDPWR` 状态位位于 bit 0。
- **SPMI 通信总线**：仲裁器（Arbiter）物理基地址位于 `0x0800f000`，观察器（Observer）物理基地址位于 `0x09400000`。

### 驱动实现机制

按键驱动源码位于 `kernel/lilac-button-state.h`，通过在用户空间构建中添加 `--buttons` 选项启用（要求同时指定 `--touchscreen`）：
1. **寄存器读取规范**：读取 PM8998 GPIO 输入电平时，驱动严格读取状态寄存器偏移 `0x08`，并根据硬件子类型校验输入使能位。
2. **双采样软件去抖**：采样周期设置为 16 ms，驱动连续采集两次电平状态以消除机械抖动。在确认按键处于稳定状态前不向系统分发事件。
3. **总线互斥保护**：SPMI 总线读写操作由内核互斥锁严格保护，与 Adreno 540 GPU 的 PMIC 电压调节操作共享锁资源，杜绝并发竞争。
4. **虚拟输入桥转发**：按键状态解析完毕后，统一打包发送至 `/dev/hakios-touch` 字符设备，由虚拟 HID 桥服务映射为 iOS 原生音量与锁屏按键事件。

## 后置相机子系统调研

### 硬件拓扑与寄存器分布

设备树 `qcom,camera@0` 描述了后置摄像头的硬件拓扑：
- **控制接口（CCI）**：物理基地址位于 `0x0ca0c000`，挂载于 Master 0，I²C 从机设备地址为 `0x20`。
- **物理层与接口（CSIPHY / CSID）**：连接至 CSIPHY 0 与 CSID 0 控制器，主时钟 MCLK 配置为 24 MHz，传感器复位引脚位于 SoC GPIO 30。
- **电源供电**：后摄模拟供电（VDIG）由 SoC GPIO 21 控制的固定稳压器提供，数字 I/O（VIO）由独立 GPIO 控制，对焦马达供电（VAF）由 PM8998 稳压器供给。

### 后续适配关键技术需求

相机子系统的完整驱动适配仍需完善以下关键环节：
1. **传感器寄存器模式表**：高通平台相机传感器（IMX400 / SOI20BS2 模块）的初始化序列、曝光与增益模式寄存器表通常存放在专有用户空间库或配置文件中，需提取并校验准确的寄存器序列。
2. **CSIPHY 5.0.1 驱动**：实现 CSIPHY 控制器物理层时钟通道与数据通道校准。
3. **VFE 与 DMA 内存通路**：配置高通 VFE（Video Front End）硬件管道并打通 SMMU 连续物理缓冲区，实现图像原始帧（RAW / Bayer）的硬件 DMA 捕获。
4. **用户空间图像管道**：在 Darwin 用户态实现与 CoreMedia / AVFoundation 的格式转换及帧缓冲适配。
